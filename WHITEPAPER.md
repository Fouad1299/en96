## 1. Executive Summary

EN96 Ice Bear Kingdom is a digital asset and community rewards ecosystem combining a Stellar-based token with a Telegram virtual-mining application.

The project aims to encourage community participation through virtual mining, interactive activities, video gift codes, and digital rewards.

EN96 also has a token contract on BNB Smart Chain. A cross-chain bridge is being developed to support transfers between Stellar and BNB Smart Chain without increasing the unified token supply.

Virtual mining is a reward simulation. It does not perform blockchain proof-of-work mining or generate cryptocurrency through computational hashing.

- Cross-chain interoperability between Stellar and BNB Smart Chain.

## 4. Unified Token Supply

The project adopts a maximum unified supply policy of 90 billion EN96 across both supported networks.

The intended bridge accounting model is:

- EN96 transferred from Stellar to BNB must be backed by EN96 locked or otherwise verifiably reserved on Stellar.
- EN96 returned from BNB to Stellar must be removed from the corresponding BNB representation before the backed Stellar tokens are released.
- Bridge transfers must not be treated as newly created unbacked supply.
- Permanent token burning, when implemented and verifiable, should reduce the corresponding supply.

The 90-billion figure is a project supply policy, not a claim that all tokens are circulating or available for trading.

Independent verification of circulating supply, reserve balances, and bridge backing is required before making claims about live bridge solvency.

## 5. Virtual Mining

EN96 provides a Telegram-based virtual-mining experience.

The currently configured base reward rate is:

**0.001 EN96 per second**

A standard virtual-mining session lasts:

**24 hours**

The theoretical base reward for a full 24-hour session is:

**86.4 EN96**

Rewards are subject to the application's server-side rules, successful processing, and applicable limits.

The displayed mining rate is not a physical hashrate, and the application does not mine new blockchain blocks.

Virtual-mining rewards do not independently increase the authorized unified token supply.

## 9. Cross-Chain Bridge Architecture

The proposed EN96 bridge connects Stellar and BNB Smart Chain.

The bridge design includes:

- Stellar deposit verification.
- Authorized validator signatures.
- Deposit replay protection.
- Backed token minting on BNB Smart Chain.
- Return requests and token burning.
- Administrative pause controls.
- Supply accounting and transfer limits.

Bridge contracts have undergone local development and testing.

**The cross-chain bridge is not yet launched as an operational BNB Mainnet service.**

No user should send assets to an unannounced bridge address or assume that a bridge transaction will be processed.

Before production launch, the project intends to perform additional security verification, configure production validators, and publish the applicable bridge addresses and operating procedures.

## 10. Security Principles

The project aims to follow these security principles:

1. Avoid exposing private keys or wallet recovery phrases.
2. Use publicly verifiable blockchain transactions.
3. Require server-side validation of application rewards.
4. Prevent duplicate bridge-deposit processing.
5. Maintain transparent accounting of bridged assets.
6. Separate development environments from production systems.
7. Restrict privileged operations and provide emergency controls.

These are design goals and do not constitute a claim of an independent security audit.

No independent audit certification is claimed in this document.
